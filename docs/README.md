# Documentation

This folder contains the documentation for the Data Engineering training project, organized by project phase (data source access, ingestion, batch processing, streaming processing and presentation).
The data source is the Bluesky Jetstream, a public WebSocket stream that delivers real-time JSON events (posts, likes, reposts, follows) without requiring API keys.
Each phase document describes the components used, how to run them and the structure of the data at that stage of the pipeline.
